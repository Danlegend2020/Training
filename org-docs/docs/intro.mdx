# Welcome to the Documentation Portal

## Overview

This documentation portal provides a centralized knowledge base for cloud infrastructure, DevOps practices, onboarding guides, and security procedures within the organization.

It is built using **Docusaurus** and deployed on **Azure Static Web Apps**, enabling automated CI/CD workflows and scalable static hosting.

---

## What You Will Find Here

### ☁ Cloud

Guides on Azure fundamentals, cloud architecture, and core services.

### ⚙ DevOps

Documentation covering CI/CD pipelines, Infrastructure as Code, containerization, and Kubernetes.

### 👥 Onboarding

Step-by-step guides for new staff setup, VPN access, and internal system onboarding.

### 🔐 Security

Policies and procedures for access control, backup, and incident response.

---

## How This Portal Works

* Content is written in Markdown (`.md` / `.mdx`)
* Stored in a GitHub repository
* Automatically built using GitHub Actions
* Deployed to Azure Static Web Apps

---

## Getting Started

Navigate through the sidebar to explore each section.

If you're a contributor:

* Clone the repository
* Add or update Markdown files in the `docs/` folder
* Commit and push changes to trigger deployment

---

## Purpose

This portal is designed to:

* Centralize technical knowledge
* Improve onboarding efficiency
* Standardize DevOps documentation
* Support scalable team collaboration
